# Real-Time Chat Application

A full-stack real-time chat application built with React, Node.js, and Firebase.

Users can register, log in, search for other users, and have one-to-one conversations with instant message updates.

## Features

- User authentication (Register / Login)
- Real-time one-to-one messaging
- User search
- Instant message synchronization
- Responsive and clean UI
- Secure authentication with Firebase

## Tech Stack

**Frontend**
- React.js
- JavaScript
- HTML / CSS

**Backend & Services**
- Node.js
- Firebase Authentication
- Cloud Firestore

## Getting Started

### Prerequisites
- Node.js installed
- Firebase project set up

### Installation

```bash
git clone https://github.com/harshhh312/Real-Time-Chat-Application.git
cd Real-Time-Chat-Application

# Install dependencies
npm install

# Start the application
npm start
```
### Project Structure
```text
src/
  components/     # UI components
  pages/          # Login, Register, Chat pages
  firebase/       # Firebase configuration
public/
```
